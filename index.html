Отчёт по занятиям YClientsПрошедшие и запланированные занятия, мастера, формат и посещаемость — в Excel

1Откуда взять данные

Данные собираются автоматически: сборщик на серверах GitHub по расписанию входит в YClients, собирает журнал записи и выкладывает результат сюда в зашифрованном виде. Чтобы открыть отчёт, введите пароль отчёта.

Проверяю, есть ли свежие данные…
  1. В YClients откройте Аналитика → Обзор → Записи.
  2. Выберите период по дате визита (например, прошлый месяц или неделю) и нажмите «Показать».
  3. Выгрузите список в Excel. YClients пришлёт ссылку на файл на почту; файл также лежит в «Обзор → Excel выгрузки».
  4. Выберите скачанный файл здесь. Можно сразу несколько — например, по разным филиалам.

Подойдёт и любая другая таблица записей, где есть дата, время, название занятия и мастер. Файл обрабатывается прямо на этом устройстве и никуда не отправляется. Ни ключ, ни пароль не нужны.

Если в YClients нет раздела «Аналитика», данные можно собрать прямо из журнала записи, который вы видите. Для этого один раз ставится закладка в браузер. Она открывает дни выбранного периода в фоне (ваш экран не меняется), а если так нельзя — сама листает журнал стрелками «‹ ›», ждёт загрузки и читает карточки занятий («(3/12) Здоровая спина», время, мастер). Только чтение: закладка ничего не нажимает внутри занятий и ничего не меняет. Имена и телефоны клиентов не собираются.

  1. Поставьте закладку. Перетащите эту кнопку мышкой на панель закладок браузера (если панели не видно — нажмите Ctrl+Shift+B, на Mac — ⌘+Shift+B):
    📋 Сбор занятий YClients
  2. Поставьте закладку (телефон, планшет). Нажмите «Скопировать код закладки», добавьте в закладки любую страницу, затем измените эту закладку: назовите её «Сбор YClients» и вместо адреса вставьте скопированный код. Запускать её нужно через адресную строку: начните вводить «Сбор» и выберите закладку в подсказках.
  4. Откройте журнал записи YClients (yclients.ru/timetable/…) на нужном филиале, режим «день».
  5. Нажмите закладку (на телефоне — начните вводить её название в адресной строке и выберите её). Появится окно сборщика: выберите период и нажмите «Собрать», затем «Открыть в приложении».
Нажимаю закладку — ничего не происходит
  • Android / Chrome на телефоне или планшете: закладка, открытая из меню «Закладки», не запускается — так устроен Chrome. Откройте журнал YClients, нажмите на адресную строку, начните вводить название закладки (например, «Сбор») и выберите её в подсказках — она отмечена звёздочкой.
  • Если короткая закладка выдала сообщение, что сайт не дал загрузить код, — поставьте полную версию закладки (около 13 000 символов; на телефоне её проще вставлять на компьютере и синхронизировать закладки):
  • Проверьте, что код вставлен целиком и начинается с javascript:. Некоторые браузеры при вставке отрезают это слово — тогда допишите javascript: в начало адреса закладки вручную.
  • Проверьте, работают ли закладки вообще: создайте закладку с адресом javascript:alert('Закладки работают') и запустите её на странице журнала. Если сообщения нет — браузер не разрешает такие закладки, используйте компьютер.
  • На компьютере без закладок: откройте журнал, нажмите F12 → вкладка Console, вставьте код из кнопки ниже и нажмите Enter. Chrome может попросить сначала ввести allow pasting — введите и нажмите Enter, затем вставьте код ещё раз.

Если окно приложения не открылось — нажмите в сборщике «Скачать файл» или «Скопировать данные» и загрузите их здесь:

Есть сохранённый вход.
Где взять партнёрский токен?
  1. Зарегистрируйтесь в кабинете разработчика маркетплейса YClients: yclients.ru/appstore/developers.
  2. Скопируйте API-ключ в разделе «Настройки аккаунта» — это и есть партнёрский токен.
  3. Логин и пароль — от вашей учётной записи в YClients; у неё должен быть доступ к журналу записи нужных филиалов.
