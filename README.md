# yclients-results — отчёт по занятиям YClients

**Открыть отчёт:** https://livesoulless.github.io/yclients-results/

Публичная часть проекта: одна HTML-страница, которая **только показывает** данные — сводку по группам (кто вёл, сколько
людей было, наполняемость), топ и антитоп по группам и отдельным занятиям, все занятия с сортировкой и фильтрами,
выгрузку в Excel. Работает на компьютере и на iPhone (Safari → «Поделиться» → «На экран „Домой“»).

Здесь нет паролей и ключей от YClients. Сбор данных живёт в отдельном приватном репозитории `yclients-downloader`.

## Откуда отчёт берёт данные

Только из облака. Приватный сборщик на GitHub Actions по расписанию собирает журнал записи и кладёт сюда файл
`data/latest.enc.json`, **зашифрованный** паролем отчёта (AES-256-GCM, ключ из пароля через PBKDF2-SHA256). Отчёт скачивает
файл и расшифровывает его прямо на устройстве. Без пароля содержимое файла прочитать нельзя.

Внутри открытого отчёта есть блок «Обновить данные» (сегодня / неделя / 2 недели / месяц) — он запускает сборщик заново.
Ручные способы («Файл», «Журнал») убраны.

Тема оформления (светлая / тёмная) переключается кнопкой в шапке и запоминается на устройстве.

Пароль отчёта задаётся в приватном репозитории (секрет `RESULTS_PASSPHRASE`); на устройстве его можно запомнить.

## Как считается

- **Группа** — одно и то же занятие в одном филиале в один день недели и время (например, «Здоровая спина», чт 09:00).
- **Наполняемость** — пришло ÷ мест. В данных из журнала отметки «пришёл / не пришёл» не видны, поэтому «пришло» = записалось.
- Формат занятия (индивидуальное / пара / группа) — по названию услуги и по вместимости или числу клиентов.

## Файлы

- `index.html` — весь отчёт (без внешних библиотек, Excel формируется самим скриптом)
- `journal-collector.js` — копия кода сборщика журнала (только читает страницу журнала); отчёт его не использует
- `data/latest.enc.json` — зашифрованные данные, их обновляет приватный сборщик
- `manifest.webmanifest`, `icon-*.png` — иконка для экрана «Домой»
